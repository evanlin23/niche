# I Simulated It — code-only YouTube pipeline

Every frame, sound and caption of the channel's videos is generated by code: deterministic
simulations → skia-drawn frames → FFmpeg, plus TTS narration and procedurally generated music.

## Quick start
```bash
make setup                     # pip deps + Piper voice (also needs ffmpeg; skia needs libEGL/libGL)
make preview SLUG=traffic-jams # 480p30 draft of the long-form (fast)
make all SLUG=traffic-jams     # 1080p60 long-form + 3 Shorts + thumbnail + source pack
make test                      # sim sanity checks
```
Outputs land in `episodes/<slug>/out/final/`:
`<slug>.mp4`, `<slug>.en.srt`, `metadata-long.json` / `description-long.txt` (title, chapters,
sources, tags), `thumbnail.png`, `shorts/*.mp4` (+ metadata), `<slug>-source-pack.zip`.

## Layout
```
pipeline/   render.py (frame-exact skia→ffmpeg), charts.py (live charts, space-time),
            tts.py (Piper | ElevenLabs, cached, word timings), music.py (procedural bed),
            timeline.py (script+scenes → cue times), compose.py (mix/duck/mux/SRT),
            metadata.py, package.py, cli.py
sims/       base.py (seeded ABM + recorder), idm.py (traffic), seir.py, boids.py, ca.py, pathfinding.py
episodes/<slug>/
  script.md     narration lines: `[id] text`
  scenes.yaml   ordered scenes: renderer, narration ids, sim window, overlays synced to cues
  shorts.yaml   9:16 shorts, re-rendered (not cropped) from the same sims, with hooks
  meta.yaml     title / description / sources / tags
  sim/scenes.py episode-specific scene renderers + thumbnail
  pack/         files added to the Gumroad source pack
```

## Making a new episode
1. Copy `episodes/traffic-jams` → `episodes/<new-slug>`; write `script.md` (check every number
   against the sim, cite sources in `meta.yaml`).
2. Build the sim in `sims/` (reuse the base class), write scene renderers in `sim/scenes.py`.
3. `make preview SLUG=<new-slug>` → iterate → `make all SLUG=<new-slug>`.

Each episode must be a different system with a different explanation, not the same template
with a new skin (YouTube "inauthentic content" policy). Backlog: `docs/backlog.md`.

## Engines / options
- `TTS_ENGINE=elevenlabs ELEVENLABS_API_KEY=... [ELEVENLABS_VOICE_ID=...]` for a premium voice
  (exact word timings). Default is local Piper (`PIPER_VOICE`, `PIPER_LENGTH_SCALE`).
- `TTS_ALIGN=whisper` (needs `faster-whisper`) for acoustic word alignment with Piper.
- `--only <scene ids>` re-renders single scenes; `--jobs N` sets parallel scene renders.
